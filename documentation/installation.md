# Installation

```bash
git clone <repo> && cd ARGUS
npm install
npm run dev
```

- Node 20 or newer, npm 10+.
- Browser with WebGL 2 (hardware acceleration enabled).
- Webcam access (Milestone 05 onward) requires `localhost` or HTTPS.
- Backend (FastAPI + SQLite) is planned for a later milestone; `backend/` is currently empty.

Scripts: `dev`, `build`, `preview`, `typecheck`, `test`.
