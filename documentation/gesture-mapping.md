# Gesture mapping

**Not implemented yet (Milestone 05).** This is the design target, not a description of working behaviour. Gestures will need calibration and may not all be reliable.

| Gesture | Intended action |
| --- | --- |
| Open palm | Activate interaction mode |
| Pinch | Select object |
| Pinch + movement | Manipulate selected object |
| Two-hand distance increase / decrease | Zoom in / out |
| Swipe left / right | Rotate camera |
| Closed fist | Pause gesture interaction |
| Three fingers | Inspection mode |
| Open palm held | Release selection |

Requirements: webcam permission requested only when gesture mode is activated, stoppable at any time, smoothing, cooldowns, interaction locking, calibration, and permanent mouse/keyboard fallback.
